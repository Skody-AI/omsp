# OMSP Governance

OMSP is maintained in public. Maintainers review proposals, merge changes, and publish releases.

## Decisions

- Editorial changes may be submitted directly as pull requests.
- Changes to wire types or normative semantics require an RFC issue followed by a pull request.
- Technical discussion and decisions take place in public issues and pull requests.
- Merging a normative change requires approval from two maintainers.
- The specification and schemas remain available under the Apache 2.0 license; no implementation
  receives private extensions or privileged access.
